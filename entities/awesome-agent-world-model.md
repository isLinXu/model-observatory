# Awesome Agent World Model

智能体世界模型方向的论文清单，按「奠基性工作 → 近期工作 → 分区」组织，正文表格在 `docs/papers.md`。

- 这份清单由机器人按**滚动窗口**维护：旧条目会被删掉以维持篇幅，所以「移出」在这类清单上是正常收缩，不是数据丢失。
- 是否当天动过、数到多少行、仓库自己徽章上写了多少——一律以「论文清单跟踪」栏目当天的快照为准，注册表只登记这个仓库，不复制任何计数。
- 它是本仓库的公开研究语料，不是模型或数据集：没有可发布的权重，也不与任何自研模型连成一条研究线。
