# Model List（HOMC 三态核实清单）

`isLinXu/model-list` 的模型清单，单位不是「一行模型」而是**一条核实声明**：README §2.0 把本轮增量拆成 🆕 新增已核实 / 🔄 更新已核实 / ⚠️ 待确认三张总表，每行按信息来源标 A（厂商一手）/ B（独立二手）/ C（单一二手或传闻），并写明「只有一个 B 源的行，日期与参数须复核」。`https://islinxu.github.io/model-list/` 由同一份 README 生成。

- 本站读的是它仓库里的 `README.md`，不解析渲染后的页面；行数、来源等级分布、单一 B 源的行数与「截至」日期的月龄，都由「模型清单核实」栏目当天的快照给出，注册表一个都不抄。
- **等级是它判的，不是本站判的**：A / B / C 来自该清单自己的信息来源列，本站不重复核实、也不替它改判，所以页面只能说「这份清单把这一行标成 A」，不能说「这一行是真的」。
- 它的提交节奏里含该仓库自己的每日自动日报，所以「这个文件多久动一次」与「人工核实表多久更新一次」是两件事，条目数与自报增量分列公布、永不相加。
