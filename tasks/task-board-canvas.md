# 任务看板画布

把「一件事由哪几块组成、谁挡住谁」画成分道画布：卡片拖动改状态，拖到别的卡上建立父子（拆解），拉出虚线建立依赖（连接）。

## 验收口径

- 拖动、连线、拆解在浏览器里可用，且键盘与触屏有等价路径（状态下拉 / 父任务下拉 / 连接到选择器）。
- 卡片座标只存本地，语义改动进仓库；未推送的草稿数量在页面上明写。
- 环、指向不存在的父任务、非法状态：当场拒绝并说明，不画出无法拖出去的线。
