# 论文精读

给定一篇论文，按下面四个阶段推进，每阶段输出必须可被下一阶段直接使用。

## 1. 问题定位

- 作者声称解决了什么问题？在什么设定下？
- 与最接近的 3 篇工作相比，新意具体在哪一句话？
- 写下来一个可证伪的假设，而不是一句形容词。

## 2. 方法拆解

- 画出数据流：输入 → 关键模块 → 输出，逐个标注张量形状。
- 对每个新增模块回答：为什么必须存在？去掉后会怎样？
- 记录所有超参数及其默认值，标注哪些是调过的。

## 3. 实验核对

- 主指标与最强基线的差距，以及这个差距需要多少算力才能被噪声解释。
- 消融是否覆盖了每个声称的贡献点。
- 是否存在数据泄漏或不公平对比。

## 4. 复现清单

输出一份可以直接开工的清单：

1. 数据来源与预处理脚本
2. 模型改动的最小 diff
3. 训练配置（步数、学习率、batch、精度）
4. 评测脚本与期望指标区间
5. 预计显存与耗时

> 纪律：任何没有在论文或代码中出现的数字，都必须标注为「推测」。
